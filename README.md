# Ehrhart Quasi-Polynomial
Repository for my master thesis on Ehrhart theory.

Includes an new algorithm to compute piecewise Ehrhart quasi-polynomials associated to matrices.
There are very optimized algorithms to compute Erhart quasi-polynomials, but not a single (publicly accessible) implementation was found for the piecewise case.

My Master Thesis was supervised by Prof. Dr. Andrew Kresch, University of Zurich, and Dr. Johannes Schmitt, ETH Zurich.
